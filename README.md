# Bootstrap Website

A multi-section educational website built with **HTML5** and **Bootstrap 5**.

The project was created to practice working with Bootstrap components, the Grid system, responsive layout, and semantic HTML structure.

## ✨ Features

- 📱 Responsive navigation
- 🦸 Hero section
- 🃏 Feature cards
- 📝 Contact form
- 🔘 Bootstrap buttons
- 🎨 Bootstrap Grid and utility classes
- 🦶 Responsive footer
- 🌐 SVG favicon

## 🛠️ Technologies

- HTML5
- Bootstrap 5.3
- SVG
- Git
- GitHub

## 📂 Project Structure

```text
bootstrap-website/
├── index.html

```

🚀 Getting Started

Clone the repository:

git clone https://github.com/SerdiukSerhii/bootstrap-website.git
